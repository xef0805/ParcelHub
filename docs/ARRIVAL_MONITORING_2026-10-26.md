# 到站监控、去重与短信凭证：0.6 验证记录

## 监控结论

本轮不使用 iPhone 快捷指令，不读取短信收件箱、微信通知或其他 App 的数据。包裹来源能打开和包裹数据能读取分别验证。

|---|---|---|---|
| 淘宝 | 本人登录后的官方身份码、待取清单网页，用户曾在旧版真机确认可用 | 前台打开/返回时检查，前台每 120 秒检查；完整读取后更新主页，显示本轮新增件数 | 0.6 原生新逻辑需编译和真机验收；不保证官方入库数据何时更新 |
| 兔喜生活 | 官方桌面短链接目标昵称“兔喜生活”，路径与参数为空 | 可以首次试开绑定小程序首页；尚不能读取它的待取清单 | 还需消费者可授权的数据接口或可登录读取的官方网页 |
| 驿收发 | 官方桌面短链接目标昵称“驿收发”，路径为空；官网公开页面与脚本也已检查 | 可绑定打开小程序首页；尚不能监控新到站 | 官网公开导航未核实到个人全部待取清单。公开的单号轨迹查询不等于按账号发现新包裹 |
| 丰巢 | 官方桌面短链接昵称“丰巢丨寄快递丨存包丨洗护丨家政”，路径为空；官网移动版有“输入快递单号查询” | 可绑定打开小程序首页；尚不能按账号监控全部到站 | 单号逐单查询只针对已知号码，不能发现未知新包裹；尚未核实消费者聚合清单权限与可靠读取方式 |

这不是“其他平台绝无接口”的结论，而是当前尚未取得、验证适用于个人自用的完整清单来源。没有向私有接口发起请求，没有伪造 AppID、Token 或已授权状态。

## 本轮实际调查

- 用户提供的三个微信官方桌面链接均实际返回 HTTP 200，公开配置能核对目标昵称和合法微信跳转票据。只有首页路径，未提供身份码页或包裹清单。
- 驿收发官网为 JavaScript 网站。本轮读取公开首页及其实际引用的应用脚本，导航包括官网介绍、充值、协议、下载和单号轨迹查询；没有据此声明取得个人清单权限。
- 丰巢官网公开移动跳转指向 `common-h5.fcbox.com/m/pages/index.html`。实际读取该页和它引用的公开导航脚本，确认是输入单号的查询入口；没有提交真实单号或把此入口当作已接入自动监控。
- 兔喜官网在本轮部分请求中连接失败；使用已验证的微信官方首页链接，不能把失败页面当作“没有包裹”或“服务停运”的证据。
- [Apple 后台策略](https://developer.apple.com/documentation/backgroundtasks/choosing-background-strategies-for-your-app)及[进入后台准备说明](https://developer.apple.com/documentation/uikit/preparing-your-ui-to-run-in-the-background)：App 进入后台后可能被挂起，前台网页轮询不能承诺锁屏/退出后持续监控。
- 官方入口：[驿收发官网](https://www.yshoufa.com/)、[丰巢移动官网](https://common-h5.fcbox.com/m/pages/index.html)、[兔喜官网](https://tuxi.zto.cn/)。

## 去重与来源凭证

完整运单号与标准化物流公司作为优先匹配依据，去除空格、统一大小写，保留前导零。不同平台出现同一完整运单时归为一个物理包裹，各平台取件码、来源与有效状态分别保存，不把某平台的码覆盖成通用码。

无完整单号时，只在近 72 小时内保守核对相同原文，或同物流、同地点、同取件码；多个候选要求补全信息，不强行合并。尾号不能作为完整运单号。短信中不含完整单号且其他来源的取件码、地点也不一致时，无法可靠判断是否同件，不能保证百分之百去重。

旧版已保存的相同完整单号与物流记录会合并，保留已取状态与来源凭证。官方清单移除包裹时只改变该来源凭证的当前状态；其他已接入官方来源仍有效时不误删。手动已取、已删除记录不会被延迟的官方清单复活。

## 短信与删除

短信解析仍在本机完成，原文不做改写，显示“导入时间”，不冒充系统已验证消息。旧版本没有保存的原文无法恢复；重新导入同件短信可补入原记录。

名称改为 `1026包裹1号`。当日序号兼容旧版长日期名称；保留包裹的实际创建年份以区分跨年。

已取记录右滑出现红色垃圾桶，点击后从记录中移除并清除短信原文；保留本机去重标识与删除标记，避免自动同步重新生成该记录。无完整单号时的短信去重指纹仅用于本机重复识别，不作为安全校验或身份凭证。

## 验证边界

本地 Node 测试、资源登记检查和会话内网页交互已验证；原生 Swift 快照测试已更新，由用户之后的 macOS 构建执行。Windows 上没有进行 Xcode 编译和真机验收。本轮上传源码，云端编译由用户手动触发。
